📊 How each model works

👥
Collaborative Filtering

Analyses how 610 users rated 9,742 movies. Finds movies that similar users also enjoyed. Strong for discovering unexpected gems but struggles with new movies that have few ratings (cold start problem).

🎭
Content-Based Filtering

Uses TF-IDF vectorisation on movie genres and release year to find similar content. Works well for new movies but tends to recommend very similar content, reducing diversity.

🔀
Hybrid Model

Combines both approaches using weights optimised by KFold cross-validation (40% collaborative + 60% content). Achieves RMSE of 0.9964 — outperforming both individual models.
